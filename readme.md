# 🛡️ ComplianceMap Enterprise

An Enterprise Governance, Risk & Compliance (GRC) Platform developed using **Flask, SQLAlchemy, SQLite, Bootstrap, and Chart.js**.

## 📌 Overview

ComplianceMap Enterprise is a web-based application designed to help organizations manage risks, audits, evidence, and compliance activities through an interactive dashboard.

---

## ✨ Features

- 📊 Interactive Dashboard
- ⚠️ Risk Register (CRUD)
- 🔥 Risk Heat Map
- 📋 Audit Management (CRUD)
- 📁 Evidence Repository (CRUD)
- 📈 Risk Analytics Dashboard
- 📉 Compliance Score Calculation
- 🏆 Top 5 Highest Risks
- 📊 Chart.js Visualizations

## 🚀 Installation

```bash
git clone https://github.com/sthiti321/ComplianceMap-Enterprise.git

cd ComplianceMap-Enterprise

pip install -r requirements.txt

python app.py
```

Application runs at:

```
http://127.0.0.1:5000
```
